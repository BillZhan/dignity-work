# 2026-09-08 工作日志

## Dignity·Work 公益网站 MVP 开发

从零开发了「让每一份劳动，都有尊严」公益 Web MVP，完整可运行并已静态导出。

### 技术栈
- Next.js 14 (App Router) + TypeScript + Tailwind CSS + lucide-react
- Supabase 双模式：配置 env 走真实后端，未配置走本地 mock（localStorage 持久化）
- 静态导出（output: export）适配 Cloudflare Pages / GitHub Pages 免费部署

### 第一阶段：核心开发（上午）
- 6 大页面：首页 / 企业列表 / 企业详情 / 推荐+纠错 / 关于我们 / 后台管理
- 8 家示例企业 mock 数据（含 6 项权益标签 + 验证等级 L0-L4）
- 完整数据库 Schema：companies / labor_rights / submissions / supports / reports / admin_users + RLS + 触发器
- 后台管理：密码登录（默认 dignity2026）+ 仪表板/企业管理/提交审核/举报处理
- 支持去重（visitor_id localStorage）
- GitHub Actions 部署脚本 + README + 免责声明

### 关键实现细节
- 动态路由 [slug] 拆为 server(page.tsx + generateStaticParams) + client(CompanyDetailClient) 以支持静态导出预渲染
- PostCSS 配置需用 .cjs + CommonJS（否则 Next.js 报 "must export plugins key"）
- 支持数在 mock 模式用 localStorage 记录增量，避免重复刷票

### Bug 修复：卡片标签竖排挤压（中午）
- 根因：RightBadge sm 尺寸写死 w-7 h-7（28px 宽），中文标签放不下逐字换行成竖排
- 修复：去掉固定 w/h，inline-flex + whitespace-nowrap + 自适应宽度
- 增加 short 标签（社保/双休/加班费/合同/福利/安全）用于卡片，详情页保留完整标签
